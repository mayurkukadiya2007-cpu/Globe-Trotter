# 🌍 Globe-Trotter

Globe-Trotter is a web-based travel planning and exploration portal.

It helps users discover destinations, create custom itineraries, book journeys and manage their travel information from one platform.

## ✨ Features

### 👤 Customer
- Customer Login
- Discover Destinations
- Search Travel Destinations
- Create Custom Tour Plans
- Select Travel Dates
- Save and Book Journey
- View Booked Trips
- Manage Profile
- Submit Travel Reviews

### 🛠️ Admin
- Admin Login
- Dashboard
- Manage Customer Profiles
- View All Bookings
- Manage Tour Packages
- Manage Customer Reviews
- Manage Admin Profile

## 🎯 Objective

The main objective of Globe-Trotter is to make travel planning simple, organized and user-friendly.

## 💡 Problem

Planning a trip often requires using different platforms for destinations, itineraries, bookings and reviews.

Globe-Trotter brings these important features together in one platform.
